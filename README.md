
# E-Commerce Website 🛒

Welcome to the E-Commerce Website project! This web application is designed to provide users with a seamless online shopping experience while empowering administrators with efficient management tools. The application is developed using Java, JSP, Servlets, HTML, CSS, and JDBC technologies.

## Features ⭐

### 👤 User Features

✨ **User Registration & Login:** Users can create an account and log in using their credentials.

✨ **Product Browsing:** Explore a wide range of products available on the website.

✨ **Product Search & Filtering:** Search for products and filter them based on different categories.

✨ **Product Details:** View product descriptions, prices, and availability by selecting individual products.

✨ **Shopping Cart:** Add multiple products to the cart, update quantities, and remove items.

✨ **Wishlist Management:** Add favorite products to the wishlist and manage them through the profile section.

✨ **Buy Now:** Purchase products directly without adding them to the shopping cart.

✨ **Checkout & Payment:** Update delivery addresses, select payment options, and proceed with checkout.

✨ **Order Management:** View order details and track order statuses through the user profile.

✨ **Profile Management:** View and update personal account information.

✨ **Password Recovery:** Reset forgotten passwords using OTP verification.

### 🔐 Admin Features

✨ **Admin Dashboard:** Manage products, categories, users, and customer orders.

✨ **Category Management:** Add, update, and delete product categories.

✨ **Product Management:** Add new products, update existing product details, and remove products from the store.

✨ **Order Management:** View customer orders and update order statuses.

✨ **User Management:** View registered users and remove user accounts when required.

✨ **Admin Management:** Add additional administrators to share management responsibilities.

### 📧 Email Notification System

✨ **Registration Confirmation:** Send email notifications after successful user registration.

✨ **Order Confirmation:** Notify users through email when an order is successfully placed.

✨ **Shipping Notifications:** Send email updates when ordered products are shipped.

✨ **OTP Verification:** Send OTPs through email for password recovery.

## 🛠️ Skills & Technologies

- **Programming Language:** Java
- **Frontend Development:** HTML5, CSS3, JavaScript
- **Backend Development:** Java, JSP, Servlets
- **Database:** MySQL
- **Database Connectivity:** JDBC
- **Web Technologies:** HTTP, Session Management
- **Additional Features:** Email Notifications, OTP Verification, CRUD Operations
- **Tools & Platforms:** Eclipse IDE, Apache Tomcat, MySQL Workbench, Git, GitHub

## 💳 Payment Integration

The payment page is developed for demonstration purposes. A live payment gateway is not fully integrated. Demo orders can be placed using sample card information.
